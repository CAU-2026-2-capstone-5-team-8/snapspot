# 디자인 개편: 설계

날짜: 2026-10-14 · 브랜치: `design/refresh`

## 목표

앱 전체를 더 세련되게 바꿔요. 기능과 데이터는 그대로 두고, 화면 구성, 색, 글꼴, 부품만 바꿔요.

### 사용자와 정한 것 (시각 자료로 비교해서 고름)
- **구성**: A(지도 중심 + 바텀시트)와 B(카드형, 토스 스타일)를 섞어요.
  - 지도가 화면 전체를 채우고, 목록은 아래에서 끌어올리는 시트에 넣어요.
  - 시트 안은 회색 바탕 위 흰 카드예요. 지금 상황을 큰 문장으로 먼저 말해 줘요.
- **색**: 잉크 + 라임. 검정 잉크가 주인공이고, 라임은 "지금 근처"와 동선 번호에만 써요.
- **모서리**: 10px 기준이에요. 너무 둥근 형태는 피해요.
- **글꼴**: Pretendard 하나로 통일해요.

### 범위 밖
- 다크 모드
- 기능 추가와 동작 변경. 정렬, 알림, 묶음 규칙은 그대로예요.
- 앱 아이콘과 알림 아이콘 교체

| `me` | `#3B82F6` | 내 위치 점 (지도에서만) |

- 라임은 의미 하나만 가져요: "지금 근처" / "지금 갈 곳". 다른 곳에 장식으로 쓰지 않아요.
- 대비: 글자 색(`ink`, `ink2`, `muted`, `danger`, `urgent`)은 흰 바탕에서, `ink` 위 `lime`과 `lime` 위 `limeInk`도 모두 4.5:1 이상이에요. `ThemeTest`가 이걸 확인해요.

### 모서리, 간격, 그림자
- 모서리: 카드, 시트 안 상자, 버튼, 입력 칸 **10dp**. 칩과 작은 썸네일 **8dp**. 바텀시트 위쪽 **16dp**. 지도 핀은 원(장소)과 4dp 둥근 네모(쿠폰 지점).
- 간격: 4dp 단위. 화면 좌우 여백 16dp, 카드 안 여백 14dp, 카드 사이 8dp.
- 그림자: 지도 위에 뜨는 요소(로고, 상태 칩, 시트, + 버튼)에만 아주 옅게 써요. 시트 안 카드는 그림자 없이 흰색과 회색의 차이로만 구분해요.

### 글꼴 (Pretendard, OFL 라이선스, `res/font`에 내장)
| 이름 | 굵기/크기 | 쓰는 곳 |
|---|---|---|
| `display` | ExtraBold 24sp / 32 | 화면의 큰 문장 ("근처에 가 볼 곳이 2곳 있어요") |
| `title` | Bold 17sp / 24 | 카드 제목, 장소 이름 |
| `body` | Regular 15sp / 22 | 본문, 입력 |
| `label` | SemiBold 13sp / 18 | 버튼 보조, 탭, 칩 |
| `meta` | Regular 12sp / 16 | 거리, 날짜, 분류 |
| `logo` | ExtraBold 18sp | "SnapSpot" |

- Black Han Sans와 IBM Plex Sans KR는 빼요. 글자 사이 간격은 -0.02em 정도로 살짝 좁혀요(`letterSpacing = (-0.3).sp`).
- 숫자(거리, D-day, 분)는 같은 Pretendard의 Bold로 써요.

## 화면

### 홈 (`ui/home/HomeScreen.kt`)
- **지도**가 화면 전체를 채워요. 지금의 둥근 지도 카드와 모서리 가림막은 없애요.
- **위에 떠 있는 것**: 왼쪽 "SnapSpot" 칩, 오른쪽 "● 12곳 지켜보는 중" 칩(누르면 현황 화면). 그 아래 오른쪽에 내 위치 버튼.
- **바텀시트**: Material3 `BottomSheetScaffold`를 써요.
  - 접힌 높이는 화면의 약 45%이고, 끌어올리면 거의 전체로 펼쳐져요.
  - 시트 순서:
    1. 큰 문장: "지금 성수동이에요" / "근처에 가 볼 곳이 2곳 있어요". 근처가 없으면 "저장한 곳 5곳을 지켜보고 있어요"
    2. 묶음 카드(가로로 넘김): 제목, "가 볼 곳 4곳 · 걸어서 13분", 오른쪽에 잉크 바탕 + 라임 글자 "동선 보기"
    3. 장소/쿠폰 전환
    4. 목록 카드
  - 권한 안내(`Notice`)는 큰 문장 바로 아래에 둬요.
- **목록 행**: 썸네일 40dp, 이름(`title`), 메타 줄(분류 · 거리 또는 종료일). 근처면 오른쪽에 라임 칩, 아니면 거리(`label`, `ink2`).
- **쿠폰 행**: 브랜드와 혜택, D-day. 3일 안에 끝나면 D-day를 `urgent` 색으로 칠하고, 근처면 라임 칩을 붙여요.
- **+ 버튼**: 오른쪽 아래, 잉크 바탕에 라임 "+", 모서리 10, 56dp.

### 묶음 동선 (홈의 펼친 상태)
- "동선 보기"나 카드를 누르면 펼쳐져요.
  - 지도 왼쪽 위 칩이 "‹ 성수동 코스"로 바뀌어요. 누르면 닫혀요.
  - 지도에는 잉크 선(3dp)과 번호 핀이 그려져요. 장소 핀은 잉크 원에 라임 숫자, 쿠폰 지점 핀은 흰 바탕에 잉크 테두리를 두른 4dp 둥근 네모예요.
  - 시트에는 "가 볼 곳 4곳" / "걸어서 13분"(큰 문장), 오른쪽 "쿠폰 포함" 스위치(잉크 트랙 + 라임 손잡이), 순서대로 번호가 붙은 목록, 맨 아래 글자 버튼 "알림 미리보기"가 들어가요.

### 스크린샷 추가 (`ui/add/AddScreen.kt`)
- **읽는 중**: 스크린샷을 크게 보여 주고, 그 위를 잉크 반투명 띠가 훑어요(지금의 형광펜 훑기를 잉크로 바꿈). 아래에 단계 두 줄.
- **확인**:
  - 위에 "2 / 5"(여러 장일 때)와 닫기.
  - 큰 문장 "스크린샷에서 찾았어요" / 장소 이름.
  - 스크린샷을 넓게 보여 주고, 그 위에 찾은 방식을 알려 주는 흰 칩("카카오맵에서 찾았어요" 등). 점수는 확률이 아니라서 %로 보여 주지 않아요.
  - 아래 흰 카드에 종류 전환, 주소, 알림 반경, 종료일 칸.
- 쿠폰일 때는 브랜드와 혜택 칸, 그리고 "가까운 스타벅스 7곳을 지켜봐요" 안내 카드가 들어가요.
- **아래 고정 버튼**: "건너뛰기"(보조, 여러 장일 때)와 "지도에 저장" / "쿠폰함에 저장"(주요).

### 쿠폰 (`ui/coupon/CouponScreen.kt`)
- 흰 바탕이에요. 위 왼쪽에 뒤로 가기, 오른쪽에 근처일 때 라임 칩 "지금 근처 · 스타벅스 성수점 92m".
- 브랜드(`meta`), 혜택(`display`), "12월 31일까지 · D-79".
- 쿠폰 이미지를 `bg` 상자 안에 크게 보여 줘요. 바코드가 잘 보이게 이미지를 화면 폭에 맞춰요.
- 아래 고정 버튼은 "알림 테스트"(보조)와 "사용했어요"(주요)예요. 삭제는 오른쪽 위 메뉴로 옮겨요.

### 현황 (`ui/status/StatusScreen.kt`)
- 큰 문장 "앱을 닫아도" / "12곳을 지켜보고 있어요".
- 카드 1: "90칸 중 13칸 사용 · 77칸 남음"과 한 줄 막대(장소는 잉크, 쿠폰 지점은 `limeDeep`, 갱신 구역은 회색), 그 아래 항목별 칸 수.
- 카드 2: 감시 범위 지도. 갱신 구역은 얇은 잉크 원으로 그려요(카카오 지도 도형은 점선을 지원하지 않아요).
- 카드 3: 마지막 갱신 시각, 카카오 검색 여부.

### 지도 (`ui/map/SpotMap.kt`)
- 둥근 카드와 가림막은 없애고 화면 전체를 써요.
- 핀 모양:
  - 저장한 장소: 잉크 원(28dp, 흰 테두리 2dp)에 이니셜. 근처면 라임 테두리.
  - 쿠폰 지점: 흰 바탕 20dp 둥근 네모(4dp)에 잉크 이니셜. 임박 쿠폰이면 `urgent` 테두리.
  - 동선 번호: 장소는 잉크 원 + 라임 숫자, 쿠폰 지점은 흰 둥근 네모 + 잉크 숫자.
  - 내 위치: `me` 파랑 점(16dp, 흰 테두리).
- 반경 원은 장소 원 테두리를 잉크 35%, 근처면 `limeDeep`으로 칠하고, 안은 아주 옅게 채워요.
- 동선 선은 잉크 3dp예요.

## 구현 원칙
- 색, 글꼴, 모서리 값은 `Theme.kt`의 토큰으로만 써요. 화면 파일에 hex 값을 직접 쓰지 않아요.
- 화면 로직(뷰 모델, 내비게이션)은 바꾸지 않아요. 화면 파일은 배치와 부품만 바꿔요.
- 글꼴 파일은 Pretendard 정적 TTF 4개(Regular, SemiBold, Bold, ExtraBold)를 `res/font`에 넣어요. 글꼴 표에 Medium은 없어서 빼요. OFL 라이선스는 `docs/licenses/pretendard-OFL.txt`에 둬요.

## 확인
- 단위 테스트와 빌드가 그대로 통과해야 해요. 로직은 바꾸지 않아요.
- 에뮬레이터에서 바꾸기 전과 후의 화면을 비교해요.
  - 홈(시트 접힘/펼침, 장소/쿠폰 탭)
  - 묶음 동선과 쿠폰 포함
  - 스크린샷 읽는 중과 확인(장소, 쿠폰, 여러 장)
  - 쿠폰 화면, 현황 화면
  - 권한이 없을 때 안내
- 글자가 잘리거나 겹치지 않는지, 바텀시트를 끌어올렸을 때 목록이 끝까지 스크롤되는지, + 버튼이 목록 마지막 행을 가리지 않는지 봐요.
- README 스크린샷을 새 화면으로 바꿔요.
